# Inkman Studio – Tattoo Studio Jönköping

En modern, mörk tematik webbplats för Inkman Studio på Trägårdsgatan 23, Jönköping.

## 🎨 Funktioner
- Hero-video (topp)
- Sticky navigationsbar med dropdowns
- Sidomeny med tatueringsstilar
- Konsultationsinfo
- Öppettider
- Bokningsinformation (info, inget formulär)
- Instagram-flöde (aktiveras med API-nyckel)
- Google Maps karta
- Fullt responsiv design

## 🛠 Teknik
- HTML5
- CSS3 (Custom Properties, Grid, Flexbox)
- JavaScript (ES6+)
- Inga ramverk – ren kod
